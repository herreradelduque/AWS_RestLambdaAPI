## AWS_RestLambdaAPI

This repository contains a simple and scalable example of how to build a serverless REST API using AWS API Gateway → AWS Lambda → DynamoDB.
The goal is to provide a clean, minimal, and easy‑to‑extend structure for creating CRUD operations in Python using AWS managed services.

# 🚀 Architecture Overview
The project follows a classic serverless pattern:

# Code
Client → API Gateway → Lambda Function → DynamoDB
API Gateway exposes REST endpoints.
